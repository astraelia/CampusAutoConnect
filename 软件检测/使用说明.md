# 兼容独立检测器

本目录保留独立检测器的当前源码和测试，检查/记录/进程观测逻辑复用主程序services，避免规则漂移。主程序已经内嵌诊断、监测和网页抓包，日常使用优先选择主程序。

工具用于包摘要、公开runtime自检、启动/退出观察、无凭据分步复查和脱敏报告，不读取或提交校园凭据，不修改网络/正式任务/自动许可。配置导出和原始抓包不作为公开附件。

源码入口为`inspector.py`；与主程序联跑`python -m pytest -q tests 软件检测/tests`。构建脚本仅生成独立工具包，旧冻结0.1.2的规则版本为dev7，不能用作1.0.1全部规则已验收的证据。本次主发布资产仅提供主程序1.0.1，不附带旧检测器二进制。

当前程序使用与配置见[主项目README](../README.md)及[功能帮助](../docs/release/FEATURES.md)。测试只使用虚构资料或无凭据检查，不代替真实校园网验收。
