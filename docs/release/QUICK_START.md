# 校园 Wi-Fi 连接助手 · 快速开始

版本：1.0.1，Windows 10/11 x64。中蓝公寓宿舍校园网已实测自动连接；配置完整且协议兼容时设计上可用于本部各区域，本部其他区域及其他校区待验证。

1. 完整解压到本人可写的固定目录，保留 EXE 和 _internal；无需 Python。网页抓包需要本机已有 Edge/Chrome。
2. 先完整退出旧版及托盘/后台，再打开新版 CampusAutoConnect.exe 并确认 v1.0.1。旧版目录保留供回退。
3. 打开“使用帮助”，从第 01 章按顺序阅读；可以搜索问题并点击章节中的链接直接跳到操作页。
4. 发布版为空网络档案，不带账号密码和认证入口。首次按[配置指南](CONFIGURATION.md)建立自己的档案及安全凭据。同一Windows用户升级会复用本机存储；输入框留空不表示没保存，主动查询可确认当前记录。
5. “连接概览”先检测。确实待认证时再手动测试一次；已有互联网不会再次登录。先确认手动连接，再决定自动认证和登录启动。
6. 故障时进入“诊断与监测”：实际记录、独立复查、深入诊断分别标记来源。深入诊断不读取凭据、不登录。
7. “抓包与分析”开始后自动打开专用浏览器及认证页，结束后自动分析；只在该浏览器操作，不必强制切网。
8. 报告位于 EXE 所在目录 reports/会话目录，页面可打开目录。目录不可写明确失败，不改存其他位置；诊断可复制，抓包保存失败可重试。
9. “后台与启动”刷新后展开高级操作，将旧任务“修复旧版登录启动到当前版本”；未启用时再勾选登录自动启动。本版取消固定 15 秒延迟，下次本人登录 Windows 后在托盘查看，可在任务栏 ^ 中寻找。自动认证许可独立控制。
10. 日常连接默认不写完整诊断；需要记录时先开始监测。设置页自动清理默认为 7 天/20 组/50 MiB，活动及保留报告跳过，抓包默认保留；旧报告需先预览确认后纳入清理。

详细教程见内置“使用帮助”、[使用手册](USER_MANUAL.md)及[各功能说明](FEATURES.md)。发布包不替新用户配置任何真实网络或许可；同机已有配置按原规则复用。

运行配置/日志仍在 %LOCALAPPDATA%\CampusAutoConnect，账号密码仍只存 Windows Credential Manager。诊断脱敏；浏览器本地抓包保留目标主机/端口供填写档案，请私下保管。

关闭窗口按设置收起托盘；“退出程序”会取消工作并停止后台。已有登录任务不会因一次退出而删除，升级后需本人核对或修复路径。

反馈请提供版本、复现步骤和脱敏诊断，不发送账号密码、原始配置、Cookie、Token 或完整 HAR。自动化检查通过不表示真实校园网和阶段验收通过。

新电脑需重新保存 Windows 安全凭据、复核网络档案和自动许可。原生查询技术故障可受控回退，查询方式见诊断 network_query；日志 startup/timing 用于分段计时。
