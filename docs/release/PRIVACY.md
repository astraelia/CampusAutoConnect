# 隐私、默认空配置与本机存储

## 分发内容

GitHub源码与Windows发布包不包含作者的真实账号密码、SSID、IP、网关、MAC、认证主机、配置/备份、日志、报告、Cookie、Token或抓包。`config/config.example.json`为`{"schema_version":1,"profiles":[]}`，没有预设校园入口；测试中的网络、账号和密码均为虚构夹具，不供实际登录。

新电脑或新Windows用户的网络档案为空、全局自动认证关闭、登录任务未安装，HTTP及全零MAC许可不预授予。默认主题/关闭方式和报告保留策略属于普通程序默认值，不代表作者个人配置。

## 下载与本地复用的区别

相同Windows用户重新下载、升级或换解压目录，会继续读取该用户的`%LOCALAPPDATA%\CampusAutoConnect`及Windows安全凭据；因此可能看到已有档案。这不是下载包携带了作者信息，也不会因下载而自动清空本人数据。换电脑/Windows用户需要重新配置和保存凭据。

| 数据 | 存放位置 | 是否可以公开 |
| --- | --- | --- |
| 校园账号密码 | Windows Credential Manager，显式WinVaultKeyring | 不可以；不写普通文件、不回填界面 |
| 网络档案及备份 | LOCALAPPDATA应用目录的config.json/备份 | 不可以，包含SSID、认证入口等 |
| 自动认证、桌面、报告策略 | LOCALAPPDATA应用目录 | 无须随包迁移，也不作为公开附件 |
| 滚动日志 | LOCALAPPDATA应用目录的logs | 只记录白名单事件，分享前仍检查 |
| 主动诊断与生命周期记录 | EXE目录的reports | 诊断按白名单脱敏，分享前仍检查 |
| 浏览器抓包JSON/TXT | EXE目录的reports | 不公开；保留主机/端口用于本人配置 |
| 配置导出 | 本人选择的文件 | 不公开；无密码但含私人网络参数 |

软件没有云端账号、遥测或后台自动上传。独立探测及认证仅用于用户选定的网络操作；HTTP认证客户端不继承环境代理，HTTPS验证保持开启。HTTP兼容需明确许可，传输本身不加密凭据。

## 上传仓库前的边界

公开导出使用固定文件清单，不复制开发者原`.git`、本机审计证据、运行目录、第三方抓包输入或历史软件包。原始本地开发记录留在本人工作区；公开项目历史只描述版本、问题和修复，不发布现场网络参数。

构建脚本在发现reports、日志、实际配置或原始抓包时拒绝打包。发布前还应核对ZIP文件清单、SHA-256、空档案/默认关闭状态及全新用户目录检查。`.gitignore`只是辅助，不能代替对实际提交内容和历史的检查。

## 安全反馈

公开Issue仅提供版本、复现步骤、错误码和检查过的脱敏诊断。不要提供真实配置、完整HAR/cURL、Cookie、Token、账号密码或凭据截图。应用凭据不接受CLI参数和管道，也不要将其写入环境文件。

发现意外公开的秘密时先停止继续传播，通过相应服务更换已暴露凭据；不要把秘密再次粘贴进Issue。网络入口和导出文件也应私下保管。
