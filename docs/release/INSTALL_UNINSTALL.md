# 安装、升级与卸载

## 安装

本版 1.0.1 为 Windows 10/11 x64 便携目录包。完整解压到自己的固定目录，双击 `CampusAutoConnect.exe`。无需安装 Python，也不要求管理员权限。`_internal` 中包含 Python、Qt、HTTP/TLS 依赖和图标；不要移动或删除其中的文件。

EXE 尚未代码签名。请从本仓库Releases获取并核对SHA-256；不要通过关闭安全软件或系统保护完成核验。不安装系统服务，发布包不附带作者运行配置或安全凭据。

程序启动不会自动保存真实档案、创建登录启动任务或开启自动认证。用户数据放在 `%LOCALAPPDATA%\CampusAutoConnect`，安全凭据放在 Windows Credential Manager，便携程序目录不存账号密码。

诊断/抓包报告按用户要求保存在 EXE 所在目录 reports；请选本人可写目录。网页抓包依赖随包 Playwright 与本机 Edge/Chrome。凭据确认记录仅含引用、状态、时间，仍在用户数据目录；它不是密码备份。

## 升级与移动

1. 在旧版中关闭登录启动（如果以前主动启用过），再点击“退出程序”，等待后台停止。
2. 保留旧包作回退，将新版完整解压到固定新目录。不要把不同版本的 `_internal` 混合复制。
3. 打开新版，检查现有档案和设置。正常升级不会迁移或复制密码；凭据引用仍指向本机安全存储。
4. 如需登录启动，先刷新状态，展开高级操作并“修复旧版登录启动到当前版本”，保留原启用状态；尚未启用时勾选“登录 Windows 后自动启动到托盘”。任务使用固定 --startup 参数和当前用户普通权限；下次登录创建托盘并复用后台。开发不代操作正式任务。
5. 如需回退，先关闭新版任务并完整退出，再打开旧版，重新核对字段兼容与任务路径。旧 M1/M2 开发脚本只作历史实现参考，不保证理解 M3 的桌面偏好。

## 配置恢复

配置损坏时，程序保留原文件，可能展示有效备份或空档案，但不会据此信任 SSID 自动提交。先完整退出，将 `%LOCALAPPDATA%\CampusAutoConnect` 中的 `config.json` 和 `config.json.bak` 复制到自己的私密备份目录，再从实际用户目录移走有问题的配置文件，重新打开并手动重建/导入档案。不要把这些文件上传反馈；文件含网络标识。

桌面偏好 `desktop.json` 只包含主题和关闭方式，损坏时可在界面重新保存。`automation.json` 只包含全局开关；缺失时默认关闭，损坏时拒绝自动操作，不恢复可能开启的备份。
`report-policy.json` 只包含清理策略；损坏时停止自动清理，可在设置页重新保存。旧报告先预览确认，抓包默认保留；升级不需要移动旧 reports，仍可在旧目录自行保管。

## 卸载

1. 打开软件，在“后台与启动”点击“关闭登录启动”，刷新确认已关闭。
2. 如需删除本软件保存的凭据，按自己的档案记录，逐一在“安全凭据”输入相应引用并删除。共享引用只删一次；不要删除其他应用或仍需使用的凭据。
3. 点击“退出程序”，等待后台退出。确认任务管理器中没有本软件的 GUI/后台进程。
4. 在资源管理器删除本版完整解压目录。若需保留设置，保留用户数据目录；若确认不再需要，可先私密备份后删除 `%LOCALAPPDATA%\CampusAutoConnect` 这个明确目录。

删除便携目录不会自动撤销 Windows 登录任务或安全凭据，因此按上述顺序清理。仅当本机用户明确选择删除时才做数据清理；开发与自动测试不会执行这些正式卸载操作。

## 1.0.1 查询兼容与换机

原生接口优先，技术故障受控回退 PowerShell；未就绪或不可信结果继续阻止认证。升级需本人主动修复旧启动任务，才能使用新版和零固定延迟。新电脑不随 EXE 获得旧电脑的凭据，须重新保存并复核档案。32 位及 ARM64 未经验证。
