# 版本记录与已知限制

## 1.3.0 · Windows 安装程序 · 2026-11-18

- 新增简体中文安装向导。可用「浏览」选择安装位置，按需创建桌面快捷方式，并可从开始菜单启动。
- 安装版可从 Windows「已安装的应用」卸载。发布同时提供安装 EXE、便携 ZIP 及各自的 SHA-256 文件。
- 本次公开发布包含 1.1.0 至 1.2.1 的有线认证、全面诊断、Wi-Fi 抓包回填和凭据显示更新。

## 1.2.1 · 合并抓包入口 · 2026-11-17

- 移除独立抓包页。“现场抓包并回填”统一从 Wi-Fi 档案编辑器进入，支持停止保存、打开抓包目录及保存失败后重试。
- 离线帮助链接跳转到“网络档案”。已有脱敏抓包可在编辑器回填地址，也可在“诊断与监测”查看摘要。

## 1.2.0 · 配置时回填抓包 · 2026-11-17

- Wi-Fi 编辑器可启动专用浏览器。手动登录一次后，从脱敏抓包回填认证页、服务地址和 HTTPS 可信目标。
- 正常结束、关闭专用浏览器或录制中断时保存已记录内容。界面显示实际文件位置，写入失败可重试。
- 有线登录网址改由本人填写，支持从编辑器打开。自动认证使用已验证的北工大 Dr.COM 分支。
- 已保存账号和密码默认以星号遮罩，按住“显示”查看，点击“隐藏”恢复。

## 1.1.0 · 有线认证与选网 · 2026-11-17

- 识别物理有线网卡和当前 Wi-Fi。有线 IPv4 和默认网关就绪后优先检查有线，拔线后使用已连接的 Wi-Fi。
- 有线档案绑定物理网卡和 IPv4 网关。通过固定的北工大 HTTPS 网关核对会话及 Dr.COM 本地认证分支。
- 保存档案后立即进行无凭据检查。全面诊断覆盖系统、连接、配置、路由、TLS、实时协议与后台。
- 真实有线登录、插拔切换和 Windows 登录后自动认证待校园网现场复测。

## 1.0.1 · 网络查询与登录启动性能修复 · 2026-10-18

- 按 SemVer 补丁迭代，统一界面、代码、Windows 资源及成品版本；移除重复版本和“人工核验版”。
- 原生网络地址/物理属性/实际目标路由查询，有界扩容及数据校验，保留实时安全复核。
- 原生技术故障受控回退到批量 PowerShell 查询，网络拒绝不回退；记录后端和回退原因。
- 登录任务取消固定 15 秒延迟，保留网络就绪和稳定期；已有任务由用户主动迁移。
- 独立探测有界并行，取消排空工作，TLS 故障优先；增加脱敏启动及操作耗时日志。
- 用户已确认 1.0.0 当前电脑连接、登录启动和自动连接可用；本版速度、换机和其他区域单独复测。
- 正式包面向 Windows 10/11 x64。详见 [1.0.1 改进报告](../v1.0.1-improvement-report.md)。

## V1.0（1.0.0）· 登录托盘启动与报告管理 · 2026-10-18

- 登录任务改用固定 --startup，创建托盘/无托盘显示窗口，复用后台，保留安全阻塞与次数。
- 增加最近任务运行时间/结果/路径健康状态，主操作简化为登录启动开关，高级操作保留迁移入口。
- 日常连接不再自动保存完整诊断；主动监测/诊断仍可保存，生命周期固定记录不新增会话。
- 清理默认 7 天/20 组/50 MiB，启动及每 24 小时检查；跳过活动/保留/默认未纳入的抓包；旧报告先预览确认。
- 清理只处理受管固定文件，拒绝链接/联接及未知内容，失败可见且不影响认证。
- 源码/Windows 资源/成品统一 1.0.0；真实登录触发和校园网回归仍由用户验收。

## 0.1.0.dev7 · 零值会话兼容与后台、启动修复 · 2026-10-18

- 支持页面配置参数 VLAN=0；全零 MAC 由精确档案单独许可，旧配置默认关闭，导入清除。

- 新增只迁移本应用现有任务且保留启用状态的“修复旧版登录启动”，不立即执行任务。
- 独立检测器更新为 0.1.2，读取 dev7 档案和新诊断规则，仍不进行登录准备或提交。
- 全零 MAC 真实校园登录待用户手动测试；未修改正式配置、凭据或启动任务，阶段验收未通过。

## 已知限制及未验证范围

1. **现场确认按版本区分。** 用户已确认 dev7 当前环境连接及 1.0.0 当前电脑连接、登录自启动和自动连接可用；1.0.1 完整重启提速、换机和跨区域仍待分别复测。HTTP 兼容需按档案明确允许；有效 HTTPS 入口仍未确认。
2. M1/M2/M3 均尚未由用户验收；代码完成、Mock 通过、本机开发检查和人工验收分别记录。
3. 当前验证机为 Windows 11 x64，未在干净 Windows 10/另一台 Windows 11 上完成独立使用核验。
4. 没有为开发测试切断远程连接；真实 Wi-Fi 切换、睡眠/休眠恢复、长时间驻留及多个显示器缩放仍需人工补测。1.0.0 当前电脑登录后自动连接已由用户确认；不扩展为 1.0.1 或其他环境的整体验收。
5. EXE 未签名，没有安装器或自动更新。托盘图标可能位于 Windows 隐藏图标区；原图在 16/24 像素时细节减少，未重绘简化。
6. 取消/退出是协作式，等待正在执行的有界 Windows 查询、HTTP 或安全存储调用结束；不会强杀正在认证的进程。退出超时会保留窗口并明确提示重试。
7. 登录启动通过固定 `--startup` 创建托盘并复用后台；托盘不可用时显示主窗口。完整退出不删除用户主动创建的登录任务，下一次登录仍会按该设置运行。
8. 暂不实现自动更新、安装服务、公开分发或跨平台支持；HTTP 例外不绕过 HTTPS 证书校验、VPN/路由或协议门槛。
