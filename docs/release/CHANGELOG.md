# 版本记录与已知限制

## 1.0.1 · 2026-10-18

- 原生网络地址、物理属性和目标路由查询，技术故障受控回退批量PowerShell；保留实时复核。
- Windows登录任务零固定延迟、独立探测并行、取消排空、脱敏后端与耗时记录。
- 统一版本显示，保留八页桌面、托盘、凭据写后核对、抓包、帮助和报告管理。
- 首次公开分发整理：空网络档案、完整配置/功能/隐私教程、固定公开清单、拒绝运行资料打包。
- 中蓝公寓宿舍校园网已实测自动连接；本部其他区域和其他校区、1.0.1整段启动耗时及换机仍待验证。

## 1.0.0 · 2026-10-18

- 固定`--startup`登录托盘入口，复用后台，不清除故障阻塞或重试额度。
- 最近任务状态/路径健康，旧任务由本人主动修复。
- 日常连接不自动生成完整报告，生命周期固定记录；受控报告保留/清理默认7天、20组、50MiB。

## 已知限制

- 当前只适配已核对的ePortal分支，不保证协议变化后无需更新；不绕过验证码、设备限制或权限。
- 中蓝公寓宿舍成功不代表其他区域已实测，设计范围和现场结果分别记录。
- 当前包为Windows x64，未完成干净Win10/其他电脑、IPv6-only、TUN、多区域、真实睡眠/切网、长期驻留与全部DPI验证；32位/ARM64未验证。
- 未签名，无安装器或自动更新；完整保留`_internal`，不混用版本。
- 取消与退出为协作式；任务运行、进程存在和单次成功响应不等于互联网认证完成。
- 自动观察器到真实主GUI正常/异常退出的完整链路仍待验证。
- M1/M2/M3整体验收未因版本号、Mock或本次公开发布而自动通过。
