# 各功能的作用与使用帮助

适用版本1.0.1。首次操作请先读[配置指南](CONFIGURATION.md)，顺序教程见[使用手册](USER_MANUAL.md)。

<a id="overview"></a>
## 连接概览

**作用：** 查看当前互联网状态、原因、执行阶段和最近检查。

“检测网络”只做无凭据探测；“配置当前网络…”异步定位精确档案；“手动测试认证”按许可及实时门槛最多提交一次，服务端接受后仍做独立联网验证。“取消本次操作”为协作取消，系统调用需等待结束。“查看脱敏诊断”进入诊断页。

原本已联网会跳过登录，不能验证新密码。读取尝试、请求尝试、服务器接受和互联网可用分别表示不同事实。

<a id="profiles"></a>
## 网络档案

**作用：** 管理多SSID、精确目标、凭据引用和每档案许可。

使用“添加当前Wi-Fi / 手动添加”，选择条目后“编辑档案 / 删除档案”。未知、停用或有歧义SSID不读凭据、不登录。字段解释见[配置指南](CONFIGURATION.md)。

“导出档案…”供个人备份，内容含网络标识，不公开分享。“导入档案…”生成新ID/引用，全部停用，撤销自动、HTTP和全零MAC许可。删除档案不会删除其他档案可能共用的凭据。

<a id="credentials"></a>
## 安全凭据

**作用：** 用当前Windows用户的安全存储保存、更新和删除本人账号密码。

确认引用后输入新账号密码，点“保存 / 更新凭据”，同一互斥内回读一致才显示“已保存并复核”。“检查是否已保存”检查当前记录；“删除凭据”影响所有共享引用的档案。

已有账号密码不回填；历史确认有时间标记，不代表当前一定存在。查询失败不等于未保存；写后复核失败应主动检查。存储成功不表示学校接受凭据。

<a id="automation"></a>
## 后台与启动

**作用：** 在已授权网络变化、断线恢复或Windows登录后编排自动认证，并限制重试。

先完成手动连接，再开启档案自动认证和全局许可，点“保存并启动后台”。“仅保存开关”不启动进程。后台启停和登录自启动独立控制，单个开关不补齐其他许可。

登录启动以当前用户最低权限创建托盘；无托盘则显示窗口。已有后台直接复用，不通过重启清除BLOCKED或重试额度。高级操作可刷新、修复本应用旧任务到当前路径；不覆盖归属不明任务。

临时故障最多初次加两次重试，间隔5/15秒；凭据、协议、TLS、信任等故障停止，重连/唤醒不清除当前进程阻塞。修复原因后再主动管理后台，不删除活动锁文件或强杀进程。

<a id="logs"></a>
## 诊断与监测

**作用：** 用脱敏结构定位网络、目标、协议、路由、凭据存储、后台和启动问题。

1. “开始监测”后再进行需要记录的操作。
2. “独立分步复查”是另一次无凭据检查，不冒充旧操作轨迹。
3. “深入诊断（不登录）”复用生产prepare和门槛，在读凭据前返回。
4. “结束监测并保存”后打开目录，或“复制脱敏监测报告”；事件可“刷新脱敏事件”。

日常连接默认只更新内存诊断和滚动日志；主动监测、检查或保存才写完整报告。保存失败不改变认证结果，共享后台事件不能仅按时间接近归因于某次点击。

<a id="capture"></a>
## 抓包与分析

**作用：** 观察本人在专用浏览器中的认证流程，辅助核对入口和排错。

“开始抓包并自动打开认证页”先等在途认证结束，再启动独立Edge/Chrome。仅在该专用浏览器操作，程序不代填凭据或点击登录。可“重新打开认证页”，完成后“停止抓包并保存”；失败时“重试保存抓包”。已有JSON可本地“分析抓包文件…”。

全程持认证互斥，新认证返回busy，不重启后台清锁止。普通浏览器和主程序HTTP请求不在观察范围。最多600条，截断、空记录与失败明确显示。

原件不保存账号密码、Cookie、Token或完整响应，但保留目标主机/端口，仍属私密网络资料，不上传GitHub。成功摘要仍需独立联网验证。

<a id="settings"></a>
## 外观设置与报告管理

**作用：** 管理主题、关闭方式和本人诊断资料，不开启认证。

选择系统/浅色/深色、关闭收起托盘，点“保存外观与关闭方式”。报告在EXE实际目录`reports`；默认7天、20组、50MiB，启动及持续运行每24小时检查。

活动、标记保留和默认排除的抓包不强制删除；旧报告先预览确认，取消不删除。可刷新统计、预览清理或保留当前报告。只处理受管固定文件，拒绝链接/联接与未知内容，不清理配置、凭据或日志。不可写明确失败，不静默换位置。

<a id="help"></a>
## 使用帮助

**作用：** 提供12章离线教程、关键词搜索和处理路径。

点击章节目录、“上一步 / 下一步”或搜索；软件内链接可直接跳到操作页，GitHub网页版链接指向本指南。没有档案时进入帮助，用户操作失败可定位诊断。

<a id="tray"></a>
## 托盘、取消与完整退出

**作用：** 收起主窗口后继续后台运行，并安全退出。

托盘可能在Windows隐藏图标区，双击恢复，右键可检测、手动认证、管理后台或退出。关闭窗口按偏好收起；“退出程序”取消、排空工作并停止后台，失败保留窗口供重试。一次退出不会删除已启用的登录任务，需要撤销时在“后台与启动”关闭。

抓包先停止并保存，不用任务管理器强杀代替保存，不删除活动锁文件。

<a id="cli"></a>
## CLI与隔离自检

**作用：** 以控制台复用服务查询、诊断和验证。

```powershell
.\CampusAutoConnect-CLI.exe --help
.\CampusAutoConnect-CLI.exe diagnose
.\CampusAutoConnect-CLI.exe --self-check runtime
```

源码入口为`python -m campus_autoconnect.cli.main --help`。密码不接受CLI参数或管道；`scan`/`profiles`可能显示私人网络信息，不直接分享。

隔离模式`runtime/network/gui/background/credentials/startup/startup-ui/browser`对应依赖、网络后端、GUI、后台、随机虚构凭据、禁用触发临时任务、登录托盘入口和本机模拟网页，不执行真实校园认证。详见[开发验证](../testing.md)。
