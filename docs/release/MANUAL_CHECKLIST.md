## 记录方式与准备

先将本文件和“问题反馈模板.md”复制到自己的记录目录，再填写。每项只选“通过 / 失败 / 未测 / 阻塞”；失败需在模板中使用相同编号描述。不要把界面能打开、Mock 成功或浏览器已联网作为真实自动认证成功的证据。

填写环境：Windows 版本____；屏幕分辨率____；缩放____；软件版本____；操作日期____；是否远程操控____。

第一组约 10–15 分钟，远程操控时也可执行。第二组建议用虚构数据。第三组只在电脑旁、允许短暂断网时进行。第四组需在档案明确配置后由本人现场测试，真实登录尚未验证。

核验期间保留正常浏览器联网方式；若仍在远程操控，**不要切换 Wi-Fi、断开网络、重启、注销或休眠**。相关项目直接标记“未测：远程使用中”。
