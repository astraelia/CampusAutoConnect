# 常见问题与排错

| 现象或错误码 | 含义与处理 |
| --- | --- |
| 下载后没有网络/账号 | 正常，发布版本为空配置；按[配置指南](CONFIGURATION.md)添加本人网络和凭据 |
| 重新下载仍有旧设置 | 同一Windows用户会复用本地数据，与GitHub包无关；见[隐私说明](PRIVACY.md) |
| 密码框重开为空 | 正常，不回填已有秘密；主动“检查是否已保存”，区分历史和当前状态 |
| 保存成功仍不能登录 | 存储核对不代表学校接受；核对档案引用、账号后缀及错误阶段 |
| already_authenticated | 当前互联网已可用，本次跳过登录，不能验证新密码 |
| untrusted_network | 当前SSID未知、停用或有歧义，检查精确名称和唯一启用档案 |
| untrusted_target | 检查认证页、API源地址、端口、HTTPS主机和HTTP许可，不扩大为通配信任 |
| protocol_unverified / protocol_changed | 入口或实时分支未支持，做无凭据深入诊断，必要时本人网页对照抓包 |
| session_fields_invalid / session_ip_mismatch | 页面字段不完整或IPv4与当前Wi-Fi不符，等网络稳定后复查 |
| session_mac_invalid / zero_mac_permission_required | 区分格式错误与全零许可，只兼容页面实际全零，不补造字段 |
| session_vlan_invalid | VLAN格式或范围不支持；0已兼容，不擅自改成其他值 |
| route_unconfirmed | 路由或虚拟网关风险未排除，检查校园Wi-Fi和VPN/TUN，不跳过保护提交 |
| tls_error | 证书验证失败，核对学校认可入口，不关闭验证或自动降级 |
| credentials_missing | 核对引用、主动检查存储状态，必要时重新保存 |
| credential_store / credential_verify | 存储失败或写后复核失败，按状态主动检查，不发送密码 |
| manual_action | 后缀冲突、服务器拒绝或其他需人工处理情形，不无限重试 |
| busy | 检测、认证、凭据修改或网页抓包占用互斥，等待完成 |
| 全局已开但不自动登录 | 还需精确档案自动许可和后台运行；STOPPED/DISABLED/BLOCKED分别检查 |
| 启动任务正常但未联网 | 任务状态不等于认证成功，分别查看网络就绪、许可、后台与诊断 |
| 托盘找不到 | 看任务栏隐藏图标区；托盘不可用时软件显示窗口，旧任务需主动修复到新版 |
| startup_error | 区分本应用旧路径与未知任务归属冲突；不覆盖未知任务 |
| 抓包为空 | 只观察专用浏览器，不含普通窗口或主程序HTTP；不要把空记录视为成功/失败证据 |
| report_save_failed | 检查程序目录写权限、磁盘和占用，复制脱敏结果；不静默改存其他目录 |
| 取消/退出有等待 | 正在进行的Windows/DNS/HTTP调用需协作完成，不强杀正在认证进程 |
| 连接较慢 | 分别观察Windows网络就绪、原生/回退查询、Portal与验证时间；API毫秒数不是完整认证耗时 |

理论范围是配置完整且认证流程兼容的本部网络；中蓝公寓宿舍已实测自动连接，本部其他区域及其他校区未验证。1.0.1整段重启耗时、换机、睡眠和长期驻留需独立测试。

反馈前完整退出旧版，确认当前版本和操作时间，用[反馈模板](FEEDBACK_TEMPLATE.md)描述步骤与错误码。不要为复现强制断开正在远程使用的网络，不上传私人配置或原始抓包。
