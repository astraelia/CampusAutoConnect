# 安全设计与限制

本软件以精确授权、失败关闭、本机安全凭据和脱敏记录为基本边界。

- 未知、停用或有歧义SSID不读取凭据、不认证；SSID大小写精确匹配，名称本身不能证明网络身份。
- 只使用本人配置的精确入口/主机/端口；不接受通配符、URL用户信息、未经验证的重定向或自动HTTPS降级。HTTPS证书验证保持开启。
- HTTP仅适用于本人明确许可、已核对的同主机页面/配置/登录分支，**传输本身不加密账号密码**。MAC/VLAN和路由检查不能为HTTP提供加密或可靠服务器身份证明。
- 读凭据前和提交前复核网络、档案、路由、取消和自动许可；页面IPv4须与当前Wi-Fi一致，实时配置分支/端口匹配。全零MAC须额外精确档案许可，导入撤销许可。
- 认证HTTP客户端固定`trust_env=False`、不跟随跳转、不关闭TLS。活动虚拟网关及路由不确定会保守阻止提交；不修改系统代理、VPN/TUN或路由。
- 账号密码只存显式WinVaultKeyring，不回退文件；GUI不回填已有秘密，CLI不接收密码参数或管道。写后在同一修改锁内回读核对。
- 诊断/事件只记录白名单枚举、布尔值、有界计数及时间，不保存原始URL、账号、响应体、Cookie、Token或异常文本。应用不遥测、不自动上传。
- 配置导出和浏览器抓包仍可能保留私人网络目标，不能公开。源码/分发包不包含作者运行数据，见[隐私说明](release/PRIVACY.md)。
- 手动最多一次提交；自动只对明确临时故障有限重试，最多三次；密码/验证码/协议/TLS/信任等停止，重连/唤醒不清除当前进程阻塞。
- GUI和凭据/认证共用服务与跨进程互斥；抓包持同一认证锁，退出协作排空。系统调用不能强杀，Python字符串不承诺安全内存擦除。
- Windows任务仅当前交互用户、最低权限，固定动作并复核归属；启用/修复需本人主动操作。不安装系统服务、不保存Windows密码。
- 报告清理只处理受管白名单文件，保护活动/保留/默认抓包，拒绝链接/联接、未知内容和无效管理元数据；旧报告先预览确认。

当前只支持已观察的ePortal分支，不绕过验证码/MFA、设备限制或学校权限。中蓝公寓宿舍已实测自动连接；其他区域/校区、更多响应、Win10/换机、IPv6-only、VPN/TUN、真实睡眠/长期驻留与显示器缩放仍需独立验证。

公开反馈只提供版本、步骤和检查过的脱敏结果，不提交真实配置、抓包、账号密码或完整HAR。发现泄露时不要继续公开传播该秘密。
